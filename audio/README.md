# Cantonese counting audio

The `count-1.wav` to `count-10.wav` clips say「一個」to「十個」in Cantonese.
They were generated with the open-source `canto-tts` package and the
`typangaa/canto-tts-nano` model, both distributed under Apache-2.0.

- Package: https://github.com/typangaa/canto-tts
- Model: https://huggingface.co/typangaa/canto-tts-nano

The model weights are not included in this project; only the generated short
audio clips are included so the activity can play offline after the page loads.
