# 10以內加減法食物樂園

獨立的繁體中文數學練習網站，讓學生用食物籃練習10以內加法和減法。

## 建置

```sh
npm run build
```

產生的靜態網站位於 `dist/`。

## 正式網站

https://ten-math-food-playground.pages.dev/

Cloudflare Pages 已連接此 GitHub 專案的 `main` 分支，使用 `npm run build` 建置，輸出目錄為 `dist`，根目錄保留為儲存庫根目錄。推送更新後會自動部署。

四合一入口：https://market-scale-classroom.outshine-volleyball.workers.dev/
